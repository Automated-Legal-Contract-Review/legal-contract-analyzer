# AI Legal Contract Review and Risk Assessment System

An AI-powered legal document analysis platform that automates contract review by extracting clauses, identifying legal risks, checking compliance, and generating explainable recommendations using Natural Language Processing (NLP) and Large Language Models (LLMs).

## Features

- PDF and DOCX contract upload
- Automated clause extraction and classification
- AI-powered legal risk assessment
- Compliance checking against predefined rules
- Explainable recommendations for identified risks
- Contract summarization
- Structured report generation (PDF/JSON)
- Secure document management

## Tech Stack

- Frontend: React.js
- Backend: FastAPI
- AI/NLP: Groq LLM, Transformers, Sentence Transformers
- Document Processing: PyMuPDF, pdfplumber
- Database: MongoDB 
- Deployment: Render ,Vercel/netlify

## Project Goal

To reduce the time and effort required for manual contract review by providing intelligent, explainable, and automated legal document analysis for businesses and legal professionals.
